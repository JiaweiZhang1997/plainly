# 使用说明

[返回项目首页](../README.md)

## 连接模型

打开工具栏图标 → 设置 → 模型连接。点击服务商预设，填写自己的 API Key 与模型名称，测试后点击右上角“保存修改”。预设只填接口信息，不提供密钥或额度，也不保证账号能调用所有模型。

第三方中转平台：展开“接口地址与协议”，使用平台给出的基础地址、模型 ID 和对应协议。目前支持 OpenAI Chat Completions、Claude Messages、Gemini GenerateContent。密钥会发送给你填写的地址，因此应使用自己信任的平台。“接口指引”中有服务商入口和配置方法。

## 划词与默认功能

在“阅读偏好 → 启用功能”勾选解释、翻译、同语学习和英英词典，可多选。“点击问号后默认打开”决定新选区首先打开的功能。只选一项时直接进入，多选时显示标签栏。

默认选中文字后出现问号，点击才请求。也可设置自动解释或仅手动触发。Alt / Option + Shift + E 处理当前选区；浏览器右键菜单和工具栏粘贴输入也可使用。

窗口上方切换模式和语言只影响本次内容；新的选区恢复保存的默认值。解释展开后可以追问，新选区会开始新的对话。

## 输出语言

| 设置 | 行为 |
| --- | --- |
| 系统语言（界面） | 中文 / English，仅决定界面和显式跟随它的输出 |
| 解释输出 / 翻译目标：跟随系统语言 | 中文界面输出简体中文，英文界面输出英文 |
| 固定语言 | 界面切换后保持不变 |
| 同语学习：跟随原文 | 根据选中文字识别语言，用同一语言改写、解释词汇、语法和例句 |
| 同语学习：指定语言 | 使用指定语言，跳过自动识别请求 |
| 内置提示词语言 | 默认跟随界面，也可固定中文或英文；自定义模板保留原样 |

语言规则通过配置显式保存，不在后台改写固定语言。输出约束会加入请求并优先于自定义提示词里的冲突要求，但模型仍可能犯错。已有回答不会自动翻译，需要重新查询。同语学习的 A1–C2 仅控制表达难度，不强制使用英语。自动语言识别会增加一次模型请求和相应用量；短词歧义可手动指定语言。

## 免费翻译与词典

在“翻译学习”中选择 MyMemory 翻译服务，并指定原文语言。它只接收选中文字，受单次长度和服务配额限制。英英词典使用 Free Dictionary API，适合单个英文词；短语、整句和其他语言建议用翻译或同语学习。失败会显示提示，不会悄悄切换成付费 LLM。

## 提示键和窗口

问号可放在选区四角，距文字约 2 px，边缘空间不足时自动避让；大小可调 20–56 px。上传图片后移动方形选框、拖动四角裁剪，确认并保存。支持常见图片格式，最大 10 MB，最多 20 张图标；图片仅在本机处理。默认问号不可删除。

正文默认 12 px，窗口默认宽 350 px、最大高 580 px。滑块和数字输入均可调整，预览同步显示；空间不足时等比例缩小。短回答不会强制占满最大高度。

拖动标题栏或六点手柄即可移动窗口。默认拖动后锁定，点击空白处不关闭；锁定按钮可临时切换，× 和 Esc 始终能关闭。设置里可开启拖动后点击外部关闭。旧窗口保留时再次选词仍会出现问号，点击后在原位置替换内容。

“目标输出字符数”是解释及追问的篇幅目标，和字号不同，不强行截断模型回答。

## Jev 搜索

在“页内搜索”单独填写 Jev API Key；也可设置兼容代理地址和自定义排序提示词。点击工具栏里的搜索入口，或按 Alt / Option + Shift + F，用一句话描述想找的内容。

默认自动按段落、句子切分，长页面分批检索。只有点击搜索后才读取并发送已加载正文片段。点击结果会滚动到原文并高亮。未加载内容、图片和内嵌页面不在检索范围内；页面过长时会显示覆盖范围，不保证找全。

## PDF

默认保留浏览器原生阅读器：选中 PDF 文字 → 右键 → 在侧栏解释 / 翻译。原生阅读器无法注入普通网页式问号，这是浏览器页面隔离带来的限制。

需要问号、全文检索和原文高亮时，可切换到释义 PDF 阅读器，或在设置里开启自动切换。工具栏的“PDF 阅读器”也能打开本地文件或在线链接。文件上限 50 MB；扫描件没有文字层时不支持 OCR。全文检索最多读取前 200 页，另有正文长度上限，未覆盖部分会提示。

通过 `file://` 地址打开本地 PDF，需要在扩展详情中开启“允许访问文件网址”。也可以在内置阅读器直接选择文件。

## 保存、用量与隐私

设置修改后点击右上角“保存修改”，或 Ctrl / Command + S。预览不代表已经保存。保存影响后续查询，不重写正在阅读的旧回答。

用量统计只累计本机扩展请求的服务商实际返回字段，包括连接测试、语言识别、Jev 分批请求。不提供用量的接口会标为未提供，不估算为零；断流、取消可能造成少计。免费翻译、词典和本地缓存命中不增加 LLM token。

设置和密钥保存在本地扩展存储，未加密为系统钥匙串，也不同步。服务商会按其政策处理收到的文字。扩展没有分析追踪或自动后台扫描。“关于释义”可查看完整规则、隐私说明和清除短期缓存；清缓存不删除配置。

## 常见问题

- **没有问号**：确认设置已保存、触发方式正确，且当前域名未被排除。刷新页面。输入框、浏览器内部页和 Chrome 商店等受限页不支持自动划词。
- **更新后重复或失效**：在扩展管理页点击重新加载，再刷新旧网页。通常不必重启浏览器或卸载；卸载可能丢失配置。
- **输出语言不符**：检查该功能的固定 / 跟随设置、临时语言和提示词，保存后重新查询。
- **401 / 403**：检查服务商密钥、账号权限与接口地址。不要把完整密钥贴到 Issue。
- **模型不存在 / 429**：确认模型 ID、额度与速率限制；预设不等于已开通对应模型。
- **搜索结果不完整**：确认正文已经加载，并查看面板显示的覆盖范围。
