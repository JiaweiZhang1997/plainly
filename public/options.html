已有平台：去哪里获取 API Key

打开对应平台的官方指引，登录并在密钥管理中创建 Key，再回到本页填写。按平台要求开通 API 服务、额度和模型权限。

DeepSeek ↗开放平台 → API keys，创建密钥。 OpenAI ↗API 平台 → 项目 → API keys，创建项目密钥。 Claude ↗Claude Console → API keys，创建密钥。 Gemini ↗Google AI Studio → API Keys，选择项目并创建。 通义千问 ↗阿里云百炼 → API Key；密钥与接口地域需一致。 Kimi ↗Kimi 开放平台 → API Keys；K3 需开通充值权限。 GLM ↗智谱开放平台 → API Keys；模型版本可自行修改。 OpenRouter ↗平台 → Keys；可用一个 Key 调用平台提供的不同模型。 Jev · TypeSafe ↗按官方快速开始获取 Key，再填入「页内搜索」。

OpenRouter 默认的 openrouter/auto 会自动选模型，按实际模型计费；可在「模型名称」指定平台列出的完整 ID。这里接入的是各平台的 API 服务，请确认账户的 API 额度。

接入其他平台或第三方 API
  1. 点击「＋ 添加模型配置」，服务商选择「自定义 / 本地模型」，给配置起一个便于识别的名称。
  2. 在第三方平台创建 API Key，填写该平台给你的完整「模型名称」。模型显示名与调用 ID 可能不同，请复制文档里的 model 值。
  3. 展开「接口地址与协议」。将文档的 base_url 或 baseURL 填入「API 基础地址」，保留它要求的版本路径。
  4. 按平台提供的协议选择：标注 OpenAI 兼容或 Chat Completions 就选「OpenAI Chat Completions 兼容」；原生 Claude Messages 或 Gemini Generate Content 接口选择对应协议。协议由平台接口决定，与调用的模型品牌无关。
  5. 填入该平台的 Key，点击「测试连接」。成功后点击「设为当前使用」，再点顶部「保存修改」。测试会发送一条简短请求。

测试连接失败时，先检查这些
  • 未获授权：检查 Key 是否有效、是否属于这个平台和地域，以及模型权限。
  • 找不到接口或模型：核对基础地址中的版本路径，以及模型完整 ID。
  • 参数不接受：核对协议；若平台明确提示不支持 stream_options，在「接口地址与协议」关闭「请求返回流式 token 用量」后重试。
  • 额度不足或请求频繁：查看 API 余额和平台速率限制。
  • 网络连接失败：检查网络与平台状态，确认平台允许浏览器扩展访问。本地服务需运行中，并按服务文档允许扩展来源。

远程地址需使用 HTTPS。本地服务可用 http://localhost:11434/v1 等地址，模型名填写已安装的模型；本地接口允许留空 Key。若平台要求的接入方式超出上述范围，仅修改地址不能完成接入。

怎么找

自定义 Jev 排序提示词和相关性判断标准 ↗

打开普通网页，点击插件里的“在当前网页找一找”，或按 Alt + Shift + F。描述想找的内容，点击搜索；点击结果会滚动到原文并高亮。

只有开始搜索时才会提取并发送已加载的正文。长页面会分批搜索，超过范围时会明确提示。结果是可能相关的几处线索，不保证找全。PDF 请通过插件中的“PDF 阅读器”打开，可搜索文档文字并跨页定位。扫描件没有文字层时不支持检索；图片、内嵌网页及尚未加载的网页内容暂不支持。

Jev 密钥仅保存在本机扩展存储中。近期搜索结果最多缓存 10 条、10 分钟；可在“关于释义”中清除。

释义使用说明

开始使用与保存设置
  1. 在“模型连接”中选择服务商，填入自己的 API Key 和模型名称，测试连接后保存。
  2. 在“阅读偏好”选择启用的功能和默认打开项。在普通网页选中文字，再点击旁边的问号。
  3. 右上角“保存修改”始终可用，也可按 Ctrl / ⌘ + S。设置页中的预览不代表已经保存。

保存的配置用于后续查询；正在阅读的旧回答不会自动重新生成。切换语言或模式会发起新的请求。

前往模型连接 ↗前往阅读偏好 ↗
语言规则：跟随、固定与原文

“系统语言（界面）”位于“阅读偏好”顶部，可选简体中文或 English。这里的“系统”指插件界面语言，不是操作系统语言。

解释输出

新配置默认“跟随系统语言”，也可指定固定语言。

翻译目标

新配置默认“跟随系统语言”，对 LLM 和免费翻译都生效；也可指定固定目标语言。

同语学习

默认跟随选中文字的主要语言：中文用中文、日文用日文、英文用英文。可手动改为跟随系统或指定语言。

“跟随系统语言”是一项明确保存的选择，配置会显示当前对应语言。切换界面语言只影响选择了“跟随”的输出；固定语言不会被改写。已有配置中的固定中文也会保留。

如需让已有的解释和翻译一起跟随界面，在“阅读偏好”顶部点击“让解释和翻译跟随系统”，再保存。每一项也能在对应配置中单独修改。

例如：界面改为 English 后，跟随系统的解释和翻译会输出英文；固定为日语的仍输出日语；默认同语学习遇到中文原文仍使用中文。A1–C2 表达难度不会强制输出英文。

原文、已生成的回答、自定义提示词及自定义名称保持原样。未修改的内置模式名称和简介随界面切换。英英词典保留英文释义，搜索摘录保留原文语言。所有生成模式都按本次语言配置追加独立约束。

设置界面与解释语言 ↗设置翻译与学习语言 ↗
功能选择与临时调整

解释、翻译、同语学习和英英词典可以多选，共用一个问号入口。“点击问号后默认打开”决定新选区首先使用的功能；只启用一项时不显示功能标签。Jev 搜索使用独立入口。

解释框上方可切换解释模式、翻译目标或学习语言。这些是当前查询的临时选择，不会覆盖已保存的默认配置；新的选区恢复默认。翻译引擎、源语言、学习注释和表达难度在“翻译学习”中设置。

展开解释可以继续追问。点击新选区的问号后开始新的内容，不会沿用上一次的追问对话。选中文字最多处理 4,000 字符。

Alt / Option + Shift + E 处理当前选区，Alt / Option + Shift + F 打开页内搜索。快捷键可在浏览器的扩展快捷键页面调整。工具栏也支持粘贴文字后手动提交。

设置启用功能与默认打开项 ↗
拖动、锁定与关闭

拖动标题栏或六个点可以移动提示框。六个点是拖动手柄，聚焦后也可用方向键移动，按住 Shift 加大步长。

默认拖动后自动锁定，点击空白处不关闭；开启“拖动后点击空白处关闭”后，拖动仍保持未锁定。标题栏的锁图标显示实际状态，点击即可临时锁定或解锁。手动选择的锁定状态优先于拖动规则。

未锁定时点击外部会关闭；无论是否锁定，× 和 Esc 都能关闭。锁定或拖动后仍可选中新文字并唤出问号，点击后替换当前内容并保留窗口位置。在保留窗口时，即使开启自动解释，新选区也需点击问号确认。

设置拖动后的行为 ↗
图标、文字与窗口尺寸

提示键可放在选区四角，距文字约 2 px，靠近屏幕边缘时自动避让。图标大小可调为 20–56 px，默认 24 px。

上传图片后，在完整原图上移动方形选框、拖动四角调整裁切范围，确认后加入可选图标列表。支持 PNG、JPG、WebP、GIF、SVG、ICO，最大 10 MB；图标会转换为静态方图，最多保存 20 张上传图标。

默认问号不可删除；内置头像和上传图标均可删除。删除正在使用的图标会切回问号。图标的选择、上传和删除都需要保存后生效。

正文为 6–24 px，默认 12 px；窗口宽度为 200–800 px，默认 350 px；最大高度为 180–1,000 px，默认 580 px。默认值位于滑块中点，也可直接输入数值。已有自定义值会保留。

右侧预览同步展示尺寸，空间不足时等比例缩小。高度设置是上限，短回答按内容收紧，长回答在框内滚动。展开追问时增加 90 px 宽度，并受屏幕空间限制。宽高仅用于网页与释义 PDF 阅读器中的浮动框；浏览器侧栏的宽度由浏览器控制。

“目标输出字符数”与字号不同：它是解释及追问的篇幅目标，范围 50–5,000 字符，包含标点和空格，不强行截断回答，也不限制翻译或同语学习。

设置图标与阅读外观 ↗
模型、免费服务与自定义提示词

模型预设包括 OpenAI、Claude、Gemini、DeepSeek、通义千问、GLM、Kimi 和 OpenRouter。预设只帮助填写接口信息，可用模型和权限以你的服务商账户为准。Jev 密钥在“页内搜索”单独配置。

第三方平台需要填写它提供的 API Key、接口基础地址和准确模型名，并选择匹配的协议：OpenAI Chat Completions、Claude Messages 或 Gemini GenerateContent。“模型连接”中的接口指引提供获取密钥和配置方法。测试连接会真实请求服务，可能产生费用；测试成功后仍需保存。

免费翻译使用 MyMemory，只发送选中文字，需要明确源语言；免费英英词典使用 Free Dictionary API，适合单个英文词。短语、整句或其他语言可使用同语学习。免费服务失败时会提示，不会自动改用收费 LLM。

“提示词 → 内置提示词语言”默认跟随界面，可固定为中文或英文。内置通用模板、解释模式、请求说明及快捷追问一起切换，下方编辑器显示实际使用的模板。修改过的模板保留原文，恢复默认后重新参与切换。提示词语言不等于输出语言：固定输出语言与同语学习跟随原文的规则仍然有效。

解释、翻译、同语学习及 Jev 排序都可以在“提示词”中自定义。修改默认模板时请保留需要的变量：解释使用 {{language}}、{{length}} 和 {{modePrompt}}；翻译使用 {{sourceLanguage}}、{{targetLanguage}} 和 {{translationNotes}}；学习使用 {{level}} 和 {{learningLanguage}}。

解释、翻译、同语学习和追问都追加独立的输出语言约束，语言配置优先于模式和自定义提示词中的冲突要求。正文、小标题、释义、语法与例句使用同一输出语言；必要原词和专名可以保留。自动同语学习仅按选中文字判断语言，上下文只用于消歧。自定义提示词保留原文。

自动同语学习会先向当前模型发送选中文字，单独识别原文语言，再将识别结果写入输出语言约束。识别不发送附近上下文；短期内相同文字可复用结果。识别请求会计入用量，可能增加等待时间；手动指定语言可跳过。无法识别时会提示手动选择，不会静默改用界面语言。短词及多语言共有词可能存在歧义，可手动指定。

PDF 与受限页面

默认保留浏览器原生 PDF 阅读器。选中 PDF 文字后右键，可在侧栏解释或翻译，无需重新打开文档。原生阅读器不允许普通扩展注入网页式划词窗口，因此这里不会出现选区旁的问号，也无法取得附近上下文。

需要选区旁的问号、全文语义检索或原文高亮时，可从侧栏切换到释义 PDF 阅读器；也可在“阅读偏好”开启自动切换，默认关闭。工具栏中的 PDF 阅读器支持手动打开文档。

通过本地文件网址读取 PDF 需要在扩展详情中开启“允许访问文件网址”，也可在释义阅读器手动选择本地文件。阅读器最多打开 50 MB 的 PDF；扫描件没有文字层时无法划词或搜索，目前不提供 OCR。

浏览器内部页、Chrome 应用商店等受限页面不能显示划词窗口，可复制文字到工具栏中使用。输入框和可编辑区域默认不自动触发；网站例外列表只关闭对应域名的自动划词，仍可手动触发。

Jev 搜索与原文定位

在插件中点击“在当前网页找一找”，描述想找的意思后开始搜索。自动切分优先保留段落，长段按句拆分；也可选择按句或按段。搜索面板中的临时选择不会修改已保存的默认切分方式。

只有主动开始搜索时才提取并发送已加载的正文片段与搜索描述。点击结果回到原文并高亮。语义结果是可能相关的线索，不保证找全；图片、内嵌页面和尚未加载的内容不在检索范围内。

PDF 全文搜索需使用释义阅读器，发送的是提取的文字片段。最多读取前 200 页，并受正文长度上限限制；覆盖不完整时会显示提示，请结合原文确认。

数据、用量与缓存

API Key 和设置保存在本机扩展存储中，不同步到其他设备，也不是系统钥匙串。密钥不会交给正在阅读的网页；上传图标在本机裁切处理。没有账户系统、分析追踪或后台页面扫描。

LLM 功能向你选择的模型服务发送选中文字、按设置启用的附近上下文、系统提示词及当前解释的追问记录。MyMemory 接收选中文字，词典服务接收单词，Jev 接收搜索描述和正文片段。数据由对应服务商处理。

用量统计读取接口实际返回的 token 字段，只累计此设备上本插件发出的请求，包括连接测试。它不代表整个账户用量、余额或费用。接口未提供的用量不会当作零；取消、超时或断流可能导致少计。

缓存 token 已包含在输入中，思考 token 已包含在输出中，不要再次相加。Jev 分批请求分别计数；命中本地缓存、免费翻译和词典不增加 LLM token。

近期解释最多缓存 40 条、搜索最多 10 条，均保留 10 分钟，存于扩展后台内存；后台休眠或修改设置可能清空缓存。下方按钮只清除这些缓存，不删除密钥、设置或用量统计。

常见问题与更新

没有出现问号：先检查触发方式、网站例外和页面是否受限；确认已保存设置。重新加载扩展后，已有网页需刷新，原生 PDF 请使用右键侧栏入口。

输出语言不符：检查该项是“跟随系统”还是固定语言、窗口中是否临时改过语言、配置是否保存，以及自定义提示词是否写死了其他语言。修改后重新查询；旧回答不会自动翻译。

更新插件文件后，在浏览器扩展管理页点击释义的“重新加载”，再刷新已打开的设置页和阅读网页。通常不需要重启浏览器，也无需卸载重装；重新加载会保留已保存的密钥和配置。

AI 可能误解新梗、缩写或出处。解释与搜索结果用于辅助理解，重要信息请回到原文核实。
