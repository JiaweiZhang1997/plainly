简体中文

释义帮助你理解和学习选中的网页或 PDF 内容。插件没有开发者运营的内容中转服务器，没有广告、分析 SDK 或浏览历史采集服务。调用远程模型和免费服务时，内容会直接发送至相应服务商，并非所有处理都在本地完成。

何时读取、发送哪些内容

  • 普通网页上，插件在本地响应划词以定位提示按钮。默认点击问号或主动提交后才向外部服务请求；如果你主动启用自动解释，符合设置的划词会自动请求。禁用网站和手动触发模式可在设置中调整。
  • LLM 解释、翻译和学习：发送选中文字、开启“结合附近上下文”时的附近文字、系统提示词、该次会话的追问和有限历史。选中文字最多 4000 字符，附近上下文最多 1800 字符。不需要时可关闭上下文。原生 PDF 右键入口仅获得选中文字。
  • 自动同语学习先将选中文字单独发送给当前模型判断语言，再请求讲解。手动指定语言可跳过识别；识别也计入用量。
  • Jev 页内搜索：点击搜索后，发送搜索描述及当前已加载正文的文本片段、相关标题和邻近文本。长页面最多处理 960 个片段、96000 字符，实际覆盖范围会显示。不会默认在后台搜索所有页面。
  • MyMemory 免费翻译：发送选中文字和语言方向；Free Dictionary API：发送所选英文单词。不发送你的 LLM 密钥。文本位于 HTTPS 查询参数或路径中，服务商可能记录。
  • 测试连接会真实请求所选服务，可能产生费用。API Key 仅用于向你配置的对应接口认证；自定义接口的运营者也能接收提交给它的密钥和内容。

本地 PDF、图片及网站地址

本地选择的 PDF 在浏览器内解析；仅在使用 LLM 或搜索时发送相关文本，不主动上传原始 PDF 文件。打开在线 PDF 时，浏览器向原网站获取文件，可能携带该网站所需的登录凭证。原生 PDF 侧栏交接和返回原生阅读器时，插件在本次浏览器会话中暂存相关标签页的地址和选中文字；不建立持久浏览历史。上传的图标在本地裁剪并保存在此设备，不发送给模型。站点禁用列表和页面地址匹配在本地处理。

保存、保留与删除

设置、API Key、自定义提示词、图标、站点禁用列表和累计 Token 用量保存在浏览器扩展的本地存储中，不使用 Chrome Sync 同步。密钥不提供给网页内容脚本，但本地存储并非操作系统密钥库。用量记录包含模型/服务标识、请求数、时间及服务返回的 Token 数，不保存提示词或回答正文。

回答、搜索和语言识别有最多 10 分钟的内存缓存，分别最多 40、10、40 项；后台进程终止时消失。设置 → 关于 → 清除本地缓存可清除这些缓存。打开的窗口可能仍显示当前文字，关闭相关窗口即可移除其显示状态。你可在设置中删除模型配置、密钥、图标及自定义内容；卸载插件可移除插件本地数据。浏览器会话暂存数据会在会话结束时清除，部分 PDF 交接项会随标签关闭或导航提前清除。服务商保留的数据不会因清除本地缓存或卸载而删除，请联系对应服务商。

第三方与安全

内容只直接发往你选择的模型或 Jev 端点、主动使用的免费服务，以及你打开的 PDF 原始地址；服务商会看到连接所需的网络信息（例如 IP 地址）。远程 API 要求 HTTPS；你自行配置的回环地址本地服务可使用 HTTP。服务商的数据保留、模型训练及费用规则由其政策决定，插件不作零保留承诺。请仅使用你信任的接口，避免提交不愿向该服务商披露的内容。

插件开发者不出售用户数据，不用于广告、不建立跨网站画像，也不将数据用于与阅读功能无关的用途。对 Google API 获取的信息的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。模型输出只作为文本显示，不执行返回的程序代码。

English

Plainly helps you understand and learn from selected web or PDF text. The developer operates no content relay server, advertising service, analytics SDK or browsing-history collection service. Requests go directly to the selected providers; processing is not entirely on-device.

Data and triggers

  • On ordinary pages, selection is processed locally to position the trigger. By default, external requests start when you click the question mark or submit text. If you enable automatic explanations, eligible selections can trigger requests automatically. Manual-only mode and per-site exclusions are available.
  • LLM explanations, translations and lessons send the selection (up to 4,000 characters), nearby text when context is enabled (up to 1,800 characters), prompts, follow-up questions and limited conversation history. Context can be disabled. The native PDF context-menu route receives only selected text.
  • Automatic learning makes a separate language-identification request containing only the selection. Manual language choice skips it. Identification counts toward usage.
  • Jev search sends your query and passages from currently loaded page content, including related headings and nearby text, when you run a search. Coverage is bounded by 960 passages and 96,000 characters and shown in the UI. Pages are not searched in the background by default.
  • MyMemory receives the selected text and language pair. Free Dictionary API receives the selected English word. These services do not receive your LLM key. Text appears in HTTPS query parameters or paths and may be logged by the provider.
  • Connection tests call the selected service and may incur charges. API keys authenticate only to your configured endpoint. A custom endpoint operator receives any key and content you send to it.

Files, images and addresses

Locally selected PDFs are parsed in the browser. Relevant extracted text is sent only when you use a model or search; original PDF files are not proactively uploaded. Online PDFs are fetched from their source website, potentially with credentials needed for that site. Native PDF side-panel handoff and returning to the native reader temporarily store the relevant tab URL and selection in browser-session storage, without building persistent browsing history. Uploaded icons are cropped and stored locally, not sent to models. Site exclusions and address matching are local.

Storage, retention and deletion

Settings, keys, prompts, icons, excluded sites and cumulative token usage use local extension storage, not Chrome Sync. Keys are excluded from content-script settings; local storage is not an operating-system keychain. Usage records contain model/provider identifiers, request counts, timestamps and reported token counts, not prompt or answer bodies.

In-memory answer, search and language-identification caches retain at most 40, 10 and 40 entries respectively for up to 10 minutes, and disappear when the background worker ends. Clear them in Settings → About → Clear local cache. Open windows may still display current text until closed. Delete model profiles, keys, icons and custom content in settings. Uninstalling removes extension-local data. Browser-session handoff data clears when the session ends; some PDF state is removed earlier when tabs close or navigate. Local deletion does not erase provider-held data; contact that provider.

Providers and safeguards

Requests go directly to the model/Jev endpoint you configure, free services you invoke, or the source address of a PDF you open. Providers receive network information such as your IP address. Remote API endpoints require HTTPS; explicitly configured loopback services may use HTTP. Provider policies determine retention, model-training use and charges; Plainly does not promise zero retention by providers. Use trusted endpoints and avoid content you do not want to disclose to them.

The developer does not sell user data, use it for advertising, build cross-site profiles, or use it for unrelated purposes. Use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including Limited Use requirements. Model output is displayed as text and is never executed as program code.
