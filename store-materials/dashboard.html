Single purpose

Help users understand and learn from the web or PDF text they are reading, through selected-text explanations, translation, language lessons, dictionary lookup and in-page semantic retrieval.

权限理由（可复制英文）

PermissionJustification
storageStore user settings, API keys, custom prompts/icons and aggregate provider-reported token usage locally; keep limited PDF handoff state in session storage. Chrome Sync is not used.
contextMenusOffer Explain / translate in side panel for a user’s selected text, including selections in the native PDF viewer.
scriptingInject the packaged page-search UI when the user invokes search, and initialize the packaged selection UI on existing permitted tabs after installation/update. No remote scripts are injected.
sidePanelDisplay selected text and reading results alongside the native PDF viewer without reopening the document.
declarativeNetRequestWithHostAccessImplement the optional, default-off switch to the bundled PDF reader using top-level PDF response/URL rules. Session rules let the user return a specific PDF tab to the native viewer. No rules are installed for automatic redirection while the setting is off.
https://*/* and http://*/*The core feature is selection-based reading on user-visited HTTP/HTTPS pages, not a fixed set of sites. Packaged content scripts position the selection trigger locally. HTTPS host access also allows direct calls to arbitrary user-configured compatible model endpoints and PDF source URLs; HTTP model calls are restricted in code to loopback services. Remote content is sent only on explicit invocation or after the user opts into automatic explanations. Users can restrict site access through Chrome and disable sites in settings.
file:///*Support local PDF URLs when the user explicitly enables Chrome’s Allow access to file URLs setting, including the optional PDF-reader routing. Ordinary website content scripts are not declared for file:// pages. The local file chooser remains usable without broad disk enumeration; no filesystem scanning occurs.

数据使用披露

至少申报以下实际处理的数据类别，并按提交时控制台字段核对：Website content（所选文字、上下文、搜索片段和 PDF 文本）、Authentication information（用户配置的 API Key，用于对应服务认证）、Web history（仅当前 PDF/标签交接的 URL、站点匹配，不持续收集浏览历史）、User activity（本地功能请求次数及 Token 用量记录；不跟踪点击、按键或页面停留）。其他类别取决于用户主动选中的内容及最终分发功能；不要声称会自动采集身份、付款或健康档案。

可在数据用途描述中使用：

Selected website/PDF content and user prompts are sent directly to user-configured providers solely to provide the requested reading feature. API keys are stored locally and sent only to their configured endpoint for authentication. Current PDF/tab URLs and selection handoff are temporarily handled to provide the side panel and PDF reader. Aggregate request and token counts are kept locally. There is no advertising, analytics telemetry, sale of data or cross-site profiling.

Remote code

No. JavaScript, PDF.js workers, CMaps, fonts, WASM and ICC resources are bundled in the extension. Remote model responses are treated only as text, and Jev returns structured selection data. No remote executable code is loaded or evaluated. The wasm-unsafe-eval CSP directive is used for bundled PDF.js WebAssembly modules.

Limited Use 声明

按实际行为确认商店的“不出售数据”“不用于无关目的”“不用于信用评估/借贷”等声明。支持服务商处理阅读请求，并不等于“不传输数据”。隐私政策已写明功能范围、第三方处理和本地存储。
