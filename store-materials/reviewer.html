Plainly 0.6.18 — reviewer instructions

Purpose: help users understand and learn from text they are currently reading. No extension account is required. The extension is free to install; external model/Jev charges and free-service quotas are separate.

1. Open extension Settings. The interface starts in Chinese; select English under the first Reading preferences section and Save changes. Open Languages and set the English dictionary as the default action under Reading preferences, or choose Dictionary from the reading card.
2. On an ordinary web page, select “serendipity”, click the question-mark trigger and choose Dictionary. Free Dictionary API works without an LLM key, subject to that service’s availability. The popup also accepts pasted words.
3. For free translation, select MyMemory in Languages, choose source English and target Simplified Chinese, and save. Select a short English phrase, click the trigger and select Translate. Automatic source language is not supported by this free provider; its request limit is 500 UTF-8 bytes. No silent fallback to paid LLMs occurs.
4. LLM features require a valid user-provided model API key with usable quota. In Model connections, choose a preset, enter the key/model, Test connection, and Save. Select text and try Explain with Smart, Slang, Technical terms, Acronyms and Sentences. Choose Learn for same-language lessons. Automatic Learn uses a short separate source-language detection request; explicit language choice skips it. UI language and output language are configured independently.
5. Optional Jev search requires a separate Jev endpoint/key in Page search. Press Alt+Shift+F on a normal page, type a semantic query and run it. The UI discloses that passages are sent and shows coverage. Results navigate to and highlight original passages.
6. Native PDF: select text and use the “Explain / translate in side panel” context menu. There is no question-mark overlay inside Chrome’s native reader. The optional built-in reader is available through the side panel or popup. Automatic PDF routing is off by default. To route file:// PDF URLs, enable Chrome’s Allow access to file URLs; the manual file chooser needs no file URL permission. Scanned image PDFs have no OCR.
7. Drag the reading card by its header; it pins by default. The pin button toggles persistence; X and Escape close. Adjust sizing and trigger position in Settings. Upload/crop/delete a custom icon; the question mark is always available. The store package does not include the developer’s private avatar.
8. Settings → About → Privacy & data use opens the bundled bilingual policy. Clearing the local cache removes transient answer/search/language caches. Keys and settings use local storage, not Sync. Usage is based on returned provider metadata and is not a billing dashboard.

Review access: the publisher must add dedicated limited test access in this PRIVATE dashboard field before submission if required for paid features. No credential is included in the package, listing or screenshots. Public model endpoints need HTTPS; explicitly configured local loopback services may use HTTP. Protected Chrome pages and the Chrome Web Store do not permit normal overlays.
