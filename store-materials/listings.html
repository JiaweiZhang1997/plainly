简体中文

一个问号，读懂和学会。

释义 · Plainly 是轻量的网页阅读助手：选中不熟悉的词语或句子，点击问号，在原文旁查看解释、翻译或语言学习说明。

• 解释专业术语、网络黑话、梗、缩写及复杂句子，提供五种解释模式。
• 双语翻译与同语学习：默认用原文语言讲词汇、语法和例句，也可明确指定输出语言。
• 自选模型：支持 DeepSeek、OpenAI、Claude、Gemini、通义千问、GLM、Kimi、OpenRouter 预设，以及兼容协议的第三方或本地接口。需自行填写有效 API Key、接口和可用模型；服务商可能收费，本插件不包含模型额度。
• 无需 LLM 密钥即可使用免费英英词典；MyMemory 免费翻译需指定源语言，受服务商额度和可用性限制。
• 可选 Jev 页内语义搜索：描述想找的意思，定位当前页面相关段落。需单独配置 Jev 接口和密钥；不是全网搜索，可能只覆盖长页面的一部分。
• 原生 PDF：选中文字后右键，在侧栏处理。浏览器原生 PDF 内不会出现划词问号；如需问号、全文检索和高亮，可选择内置 PDF 阅读器。扫描图片 PDF 不提供 OCR。
• 可拖动和锁定阅读窗口，调整字体、窗口尺寸、按钮位置与大小，上传并裁剪自己的图标；支持中英文界面与自定义提示词。
• 本地统计服务返回的 Token 用量；服务未返回用量时会明确标记，非账户余额或费用账单。

数据与控制
默认点击后请求，可自行开启自动解释。所选文字及开启的附近上下文直接发送给你配置的服务商；Jev 搜索会发送正文片段。API Key 保存在扩展本地存储，不经过开发者中转服务器。没有广告或分析追踪。请阅读隐私说明并仅选择信任的服务。

需要 Chrome 128 或更新版本。Chrome 内部页面、扩展商店等受保护页面可能限制插件运行。模型生成的内容可能出错，请核对重要信息。

English

One question mark. A clearer read.

Plainly is a lightweight reading companion. Select an unfamiliar word or passage, click the question mark, and read an explanation, translation or lesson beside the original text.

• Five explanation modes for unfamiliar expressions, technical terms, internet slang, acronyms and complex sentences.
• Translation and same-language learning: learn vocabulary, grammar and examples in the source language, or explicitly choose another output language.
• Bring your own model: presets for DeepSeek, OpenAI, Claude, Gemini, Qwen, GLM, Kimi and OpenRouter, plus compatible third-party or local endpoints. You supply a valid API key and available model. Provider charges may apply; model credits are not included.
• A free English dictionary works without an LLM key. Optional MyMemory translation requires an explicit source language and is subject to provider limits and availability.
• Optional Jev semantic search finds relevant passages on the current page from a description of their meaning. It needs a separate Jev connection/key. It is not web search; coverage of long pages may be partial.
• Native PDFs: select text and use the context menu to work in the side panel. The question-mark overlay cannot appear inside Chrome’s native PDF viewer. An optional built-in reader supports selection overlays, search and highlights. Scanned image PDFs have no OCR.
• Drag or pin the reading card; adjust text, card size, trigger position and size; upload and crop your own icon. Chinese and English interfaces and editable prompts.
• Local token totals from provider-reported usage. Missing usage is marked; this is not an account balance or billing statement.

Data and control
Requests start on click by default; automatic explanations are opt-in. Selected text and enabled nearby context go directly to your chosen provider. Jev receives page passages when searching. API keys stay in local extension storage and do not pass through a developer relay. No advertising or analytics tracking. Read the privacy policy and use providers you trust.

Requires Chrome 128 or later. Chrome internal pages, the Web Store and other protected pages may restrict extensions. AI output can be wrong; verify important information.
